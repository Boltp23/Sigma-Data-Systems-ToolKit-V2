# Sigma-Data-Systems-ToolKit-V2
Single-file PowerShell toolkit for MSP/IT techs. Menu of 86 Windows workstation &amp; server diagnostics, fixes and deployments: crashes, disk, updates, RDP/RDS, Hyper-V, AD, network, security, Office/app installs, plus Sysinternals &amp; NirSoft tools. Changes always ask first; reports go to C:\temp. Built-in self-test.
